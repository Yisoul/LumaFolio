# 光影册 LumaFolio

**把散落的照片，整理成作品。**

LumaFolio（光影册）是 Windows 上的本地摄影图库与作品排版工具。原图始终留在原目录，软件只保存索引和引用；多个相册、作品可以复用同一张照片，不会重复复制文件。

## 这是什么

简单说，**光影册 LumaFolio** 就是给摄影爱好者和经常在网上发图的人做的一个 Windows 本地相册 + 排版工具。

名字里的 **Luma** 是摄影里的光线、亮度，**Folio** 是作品集、图册；中文「光影册」既保留了摄影感，也更像一个正式的产品名。

我做这个软件的起因很直接：照片越来越多之后，每次想整理一组作品都很麻烦。

- 照片散在很多文件夹里，想找一组图要来回翻。
- 同一张照片想放进不同相册，只能反复复制，占空间还容易乱。
- 发小红书、朋友圈或者摄影社区之前，还要自己排版、拼图、加文字。
- 在线相册工具又要上传原图，既慢又不放心。

所以就有了这个软件。

它直接读取你电脑里现有的 JPG/PNG 文件夹，不改名、不搬运、不复制原图。相同内容的照片只算一份原图，多个相册和作品共享引用。你可以在图库里筛选、预览、分组，把照片加入不同相册，再直接做成一套排版作品，最后导出成多页图片或长图。

整个软件完全离线运行：

- 不需要注册账号。
- 不会上传照片。
- 原图默认不会被修改。
- 删除原图必须明确操作，而且只会移入 Windows 回收站。

这个项目已经开源。代码、说明和后续安装包都可以在 GitHub 获取：

**GitHub：** https://github.com/Yisoul/luma-folio

如果这个项目刚好解决了你的问题，欢迎点个 Star、提 Issue，或者直接提交 PR。

## 核心规则

- 只支持本地 JPG/JPEG/PNG，不登录、不上传。
- 相同 SHA-256 内容合并为一个照片资产，磁盘原文件不会被自动移动、重命名或删除。
- 相册和作品只保存照片引用。
- 从图库、相册移除时默认只修改应用数据库。
- 只有明确点击“删除原图”并二次确认后，才会把文件移入 Windows 回收站。
- 应用启动采用增量扫描：路径、文件大小和修改时间未变化时，不重新读取原图、不重新解析 EXIF、不重复计算哈希。

## 图库

- 索引现有照片目录，自动监听新增、改名、移动和删除。
- 完整 EXIF 信息：相机、镜头、焦距、光圈、快门、ISO、拍摄时间。
- 按文件名/路径、方向、相机、镜头、相机评星、收藏和拍摄时间筛选。
- 相机搜索支持中文和英文品牌别名，例如尼康/Nikon、佳能/Canon、索尼/Sony。
- 只读相机和修图软件写入的评星（EXIF `Rating` / XMP `xmp:Rating`，兼容 `RatingPercent`），不修改原图。
- 支持拍摄时间、导入时间、星级和文件名的升降序排序。
- 左侧是可折叠的文件夹树，按来源目录 → 子目录分层展示并带照片计数；选父目录会连子目录的照片一起筛出来。
- 文件夹是单选：点一个子目录就只筛它，「全部文件夹」和父级会自动取消选中；再点一次取消筛选。
- 左边文件夹栏可以整栏收起，左栏和右侧信息栏的宽度都能直接拖分隔条调整，宽度会记住。
- 鼠标移到某张照片上，左侧会高亮它所在的目录并把该目录滚动到可见位置，不会改变当前筛选。
- 图片按原图比例排成「对齐行」：同一行等高、宽度按比例，不裁切不拉伸，缩略图下方显示文件名、星级和像素尺寸。
- 顶部一条缩略图尺寸滑杆可以实时调整图片大小，旁边是筛选 chips（方向 / 星级 / 收藏 / 相机 / 镜头 / 拍摄时间 / 排序），点开弹层设值，有条件时高亮并可一键清除。
- 单击选中照片、右侧信息栏显示大预览和拍摄参数；`Ctrl/⌘ + 单击` 多选，双击或空格看大图。
- 支持“全部照片”模式，分页加载每页 120 张，滚动自动加载。
- 分页加载，每页 120 张，滚动自动加载。
- 支持全选已加载照片、批量加入相册和收藏。
- 双击图片进入预览；全屏时保持原图比例，方向键切换上一张/下一张。
- 预览使用缩略图缓存和相邻图片预加载，未变化的预览不会重新生成。

## 全屏浏览与选片

- 图库工具栏点「全屏浏览」或按 `F`，直接进入铺满整屏的瀑布流，继承当前搜索、文件夹、星级和收藏筛选；相册详情页也能用同一入口浏览整个相册。
- 进入时窗口切成系统全屏（盖住任务栏），退出时恢复原窗口；界面跟随浅色 / 深色主题，不再是固定黑底。
- 用 `Ctrl` + 鼠标滚轮连续调整图片大小；图片按原始比例排布，滚到底自动加载下一页（每页 120 张）。
- 单击选中，方向键前后移动，双击、回车或空格打开大图灯箱，灯箱内方向键翻页，空格或 `Esc` 退出。
- 空格看图是全局快捷键：在图库和相册里点选任意照片后按空格，同样会全屏查看，不用先进入瀑布流。
- 选中后按 `T` 把照片加入「临时选片」相册，再按一次移出。临时相册在本次全屏会话第一次标记时创建，退出后就是普通相册，可以继续用来排版或直接删除。
- 全屏内的星级筛选和「已标记 / 未标记」切换只作用于本次浏览，不会改动图库页上的筛选条件。

## 相册

- 一个照片资产可以同时属于任意多个相册。
- 相册照片支持全选、取消全选、批量移除。
- 相册封面自动取第一张照片，也可以在照片右键菜单中更换。
- 相册卡片右键可以打开或删除相册。
- 一个相册可以保存多套独立作品版本。
- 作品卡片用该作品第一页的第一张图片当封面。

## 排版编辑器

- 支持页面新增、切换和删除。
- 作品名称可以直接点击修改。
- 页面尺寸支持 `3:4`、`1:1`、`4:5`、`9:16` 和自定义像素。
- 画布支持 `50%` 到 `300%` 缩放及一键适应窗口。
- 图层支持图片和文字，可拖动、自由拉伸、旋转和调整顺序。
- 拖拽时自动吸附画布边缘、中心线以及其他图层的同边、同高和中心线，并显示参考线。
- 文字图层支持单击选中、再次点击或双击进入原生画布内编辑。
- 右侧文字输入会实时同步到画布，失焦或点击“应用文字”后保存。
- 所有文本输入框支持右键剪切、复制、粘贴和全选。
- 文字支持导入 TTF、OTF、WOFF、WOFF2 字体，并可在预览和导出中保持一致。
- 文字格式支持字号步进、颜色色板、系统字体和导入字体。
- 图片支持完整显示、裁剪填满、自由拉伸和圆角。
- 画布支持单击选中、`Ctrl` 多选、空白处或 `Esc` 取消选择。
- 图层右键菜单支持更换图片、就地编辑文字、置顶、上移、下移、置底和删除。
- 左侧图层列表提供快捷置顶、置底操作。
- 页面背景可以单独设置颜色，不影响其他页面。

## 快捷键

- `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4`：切换 图库 / 重复项 / 相册 / 设置。
- `/` 或 `Ctrl+F`：聚焦搜索框；不在图库页时会先跳回图库。
- `F`：进入全屏瀑布流（图库和相册详情都可用）。
- 空格：全屏查看选中的照片，在大图里再按一次退出。
- `←` `→` `↑` `↓`：在大图、全屏瀑布流和照片详情里切换。
- `T`：把当前照片加入或移出临时相册。
- `Ctrl+A`：全选当前已加载的照片（输入框里仍是文本全选）。
- `Ctrl+=` / `Ctrl+-`：放大 / 缩小界面；`Ctrl+0` 回到 100%。
- `Esc`：逐层回退——输入框失焦、关浮层、退出全屏、取消选中。
- 编辑器：`Delete` 删除选中图层，方向键微移（`Shift` 加大步长），`+` `-` 缩放画布，`0` 适应窗口。
- `?` 或 `Ctrl+/`：打开快捷键面板，里面按区域列出当前可用按键。
- 在输入框里打字时，单字母和空格快捷键不会触发。

## 内置模板与变量

内置 8 套模板：单图、两张横排、两张竖排、主图加两副图、四宫格、六宫格、封面加正文、四图长条。

文字支持：

- `{{album}}`
- `{{camera}}`
- `{{lens}}`
- `{{aperture}}`
- `{{shutter}}`
- `{{iso}}`
- `{{date}}`

## 导出

- 多页作品导出多张等宽图片。
- 长图作品按相同宽度纵向拼接，支持页面间距。
- 默认导出 sRGB JPEG，质量 92，也支持 PNG。
- 长边预设 1080、1440、2160。
- 长图超过 65,535 px 时会提示拆分。

## 主题与设置

- 界面采用 Eagle 风格的深色 / 浅色两套主题，切换后立即生效并持久化；旧的四色主题设置会自动回退到深色。
- 界面缩放支持 90% / 100% / 110% / 125% / 150%，在设置页切换或按 `Ctrl+=` `Ctrl+-` `Ctrl+0`，会整体缩放包括排版画布在内的所有界面元素，并持久化到本机设置。
- 默认缩略图大小可以在设置页或图库工具栏的滑杆里调整，范围 120–360px，主题和缩放互不影响。
- 字体使用系统字体栈（Segoe UI Variable / 微软雅黑 UI / 苹方 / 思源黑体），数字和路径使用等宽字体，不额外下载字体文件。
- 可配置自动监听目录和缩略图缓存上限。
- 来源目录列表支持滚动。
- 支持立即备份数据库，自动备份保留最近 7 份。

## 开发

```powershell
npm install
npm run dev
```

验证：

```powershell
npm run typecheck
npm test
npm run build
```

如果 Electron 二进制下载失败，可使用镜像：

```powershell
$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
node node_modules/electron/install.js
```

## 打包

应用图标是仓库里的 `build/icon.svg`，改完跑 `npm run icon` 会重新生成 `build/icon.png` 和多尺寸 `build/icon.ico`，打包时自动写进 exe。

只想本机双击运行、不生成安装包：

```powershell
npm run package:dir
```

输出到 `dist\win-unpacked\LumaFolio.exe`，双击即用，和开发模式共用同一份应用数据。

生成 Windows 安装包：

```powershell
npm run package
```

安装包输出到：

```text
dist\LumaFolio-0.2.0-Setup.exe
```

当前安装包未签名，Windows SmartScreen 可能显示安全提示。

## 数据位置

应用数据保存在本机应用数据目录 `%APPDATA%\luma-folio`：

- `library.sqlite`：照片索引、相册、作品和模板。
- `thumbnails`：可重新生成的 WebP 缩略图和预览缓存。
- `backups`：数据库备份，保留最近 7 份。
- `settings.json`：扫描、缓存和主题设置。
- `fonts`：导入字体文件及字体目录清单。

原图不会被移动到应用目录。

从「相册工作台」升级上来时，旧目录 `%APPDATA%\album-studio` 里的数据库、设置和导入字体会在首次启动时自动复制过来；缩略图缓存按需重新生成，旧目录保持原样不删除。

## 当前边界

只支持 JPG/JPEG/PNG；暂不支持 RAW、HEIC、云盘同步、多人协作、标签、智能相册和照片调色。
